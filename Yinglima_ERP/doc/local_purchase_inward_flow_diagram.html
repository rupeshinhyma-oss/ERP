Yinglima ERP • Local Purchase to Inward Stock Automation

Visual workflow diagram showing how Local Purchase status triggers seamless Inward Stock Movement into the warehouse ledger without manual re-entry.

PHASE 1
1. Create Local Purchase
Create domestic RMB purchase order (/purchase/local/new). System isolates vendor items and saves with initial status: Confirmed.
PHASE 2
2. Inward Trigger in Table
When goods arrive at warehouse, user clicks [📦 Inward Stock] or changes status from Confirmed → Inwarded.
PHASE 3
3. Pre-Filled Inward Slip
Modal automatically pre-fills supplier, invoice reference, products, and quantities. User verifies accepted count with 1-click confirmation.
PHASE 4
4. Real-Time Ledger Posting
System records INW-2026-xxxx in /inventory/stock-movements, updates live warehouse stock balance, and marks purchase as Inwarded.
